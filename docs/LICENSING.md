# Licensing review

This page records where the project's code and data come from, under what terms, and which licensing questions are still open.
It was first checked on 2026-11-24 using the GitHub licence API (`/repos/OWNER/REPO/license`), each repository's README and root files, the wiki's MediaWiki `siteinfo` (rightsinfo), and Jagex's published policies, and updated on 2026-11-26 when the world-save reader and the item catalog were replaced, when the editor started bundling its own generated item catalog, and again when that catalog started being built from an installed copy of the game instead of the RSDWArchive dump.
It is a good-faith review, not legal advice.

## Summary

- **Our code is MIT** (see [`../LICENSE`](../LICENSE)). Nothing upstream forces a copyleft licence: no third-party code is included. The world-save reader follows MIT-licensed format documentation (SPUD), the game-data reader follows format knowledge read in the Apache-2.0 CUE4Parse project (no code copied), and no GPL code is used.
- **No network connections.** The editor makes none: no downloads, update checks, telemetry or accounts. The catalog is bundled, and the optional rebuild reads the player's own installed game.
- **The MIT licence covers our own code only.** It does not cover Jagex game data (names, IDs) or text from the wiki.
- **No third-party code or compiled data is shipped.** The two earlier open items are closed:
  - *World-save reader.* The earlier port of OogaBoogaCode's `spud.js` / `model.js` (`world.py`) has been deleted. `dragonwilds_save_editor/spud.py` is an independent clean-room implementation written from the sinbad/SPUD (MIT) format description and the project's own analysis of real world saves; the port was not opened while writing it. The log is in [research/spud_cleanroom.md](research/spud_cleanroom.md).
  - *Item catalog and unlock names.* The old `items.json`, `items.csv`, `items_ai.tsv` and `unlock_names.json` (compiled from OogaBoogaCode, RSDWTools and RSDWArchive) have been removed. The catalog the editor now ships (`dragonwilds_save_editor/data/catalog/`: `items.json`, `unlock_names.json`, `build_info.json`) is **our own compilation of Jagex game facts** (IDs, names, stack sizes, durability, inventory tabs, unlock names), generated by our own code (`dragonwilds_save_editor/gamedata/` and `catalog.py`) from **an installed copy of the game** (version 1.0.2.2), read only. No game file and no third-party compiled list is shipped. An optional **Update item catalog** action runs the same build on the player's machine from the player's own installation, offline. An earlier version of the catalog was generated from the RSDWArchive dump (build 1.0.2.0); it is now used only for cross-checking (every ID and field agreed). See [research/catalog_build.md](research/catalog_build.md) and [research/gamedata_provenance.md](research/gamedata_provenance.md).
- **Bundled data is our own work.** The data files hold game IDs and facts read from the installed game by our own code (the item catalog; the verified map and lodestone IDs), our own analysis of the datamined quest flows and of real saves, with wiki facts paraphrased (see the table below).
- **Jagex.** A free, single-player save editor matches the Dragonwilds Community Modding Guidelines. The project carries the Fan Content Policy notice (8.1), is free and uses no Jagex logos or art (see below).
- **Personal data.** Earlier drafts of the quest data and the world-save notes named the maintainer's private worlds and other players' characters cached in them. These have been scrubbed: the worlds are now "World A" and "World B" and the guest character is "GuestChar".
- **Wiki text.** The verbatim wiki quotes that were in the quest data have been replaced by short paraphrases (`wiki_summary`) with the source URL, so the bundled data contains no CC BY-NC-SA text.

## What "no licence" means

With no licence, the author keeps all rights by default (Berne Convention; see GitHub's
[licensing docs](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)).
GitHub's Terms of Service let others **view and fork** a public repository on GitHub, but grant no right to **copy, modify or redistribute** it elsewhere. In practice:

- **Ported code is a derivative work.** A line-by-line port of `spud.js` / `model.js` into Python still copies the original's expression. Publishing it needs the author's permission; the alternative is a clean-room rewrite.
- **Bundled data from unlicensed repositories** is riskier than it looks. Single facts (an ID, a stack size) are not copyrightable, but a whole compiled catalog can be protected as a compilation, and in the UK and EU as a database (sui generis database right). Copying 1,536 entries wholesale copies the compilation.
- **Cross-checking** (reading their data to confirm ours) copies nothing and needs no permission.
- Jagex's Modding Guidelines say the same: *"Always get permission before using assets or code from other creators."* and *"No unauthorized reuploads or "mod packs" that bundle others' work."*

## Jagex's position

### RuneScape: Dragonwilds Community Modding Guidelines

Source: <https://legal.jagex.com/docs/policies/runescape-dragonwilds-community-modding-guidelines> (undated).

- Cheating: *"While single-player cheats are fine, using mods to cheat in multiplayer or any shared gameplay is prohibited."*
- Save data: *"Mods should never damage or corrupt save data or give unfair advantages in shared spaces."*
- Monetisation: *"Do not charge for mods, lock features behind paywalls, or solicit donations within the mod."* and *"No ads or affiliate links embedded in the content."*
- Credit: *"Work with others and always give credit for reused content or inspirations."*
- Other creators: *"Always get permission before using assets or code from other creators."*
- Endorsement: *"Don't falsely claim endorsement by the game developers or misrepresent your mod's features."*
- Documentation: *"Provide clear installation instructions and note if your mod changes critical gameplay features."*
- Other policies: *"All mods should comply with any relevant sections of our Terms and Conditions, EULA and the Fan Content Policy."*
- Enforcement: Jagex may act "at our discretion against mods we deem harmful, disruptive or otherwise inappropriate".

### Fan Content Policy (v1.4, 29 September 2026)

Source: <https://legal.jagex.com/docs/policies/fan-content-policy>

- **Required notice (8.1)**, placed "in a prominent and visible place" such as a readme: *"Created using intellectual property belonging to Jagex Limited under the terms of Jagex's Fan Content Policy. This content is not endorsed by or affiliated with Jagex."* This notice is in LICENSE, the README, CREDITS.md and the GUI's About box (Help > About Dragonwilds Save Editor).
- **Trademarks (2.4):** the policy does not cover Jagex's trademarks, and in particular the Jagex logo "should never be used without our permission".
- **Software (6.1.3):** *"You can't make any form of video game content using Jagex Property, which includes custom quests or add-ons for integration into one of our games, except for modifications or plugins created in accordance with paragraph 4.1.6 above. … We realise that many of you have good intentions in creating companion, guide and other apps … we cannot therefore allow the use of Jagex Property in this context"*. Paragraph 4.1.6 allows *"modifications and plugins as part of official programs for RuneScape Games, provided that you comply with these rules, the terms of our EULA and any associated guidelines."* The Dragonwilds Modding Guidelines are the nearest thing to such a programme. Whether a stand-alone save editor that bundles item names counts as a "modification" is **not stated**.
- **Reverse engineering (6.1.2):** *"You can't reverse engineer any of our games or create a means of accessing them via a third-party client"*. Editing one's own save files is not decompiling the game. The catalog builder reads data files of the player's own installed copy (names, IDs, stack sizes), the way asset viewers do; it does not decompile or read the executable, attach to the running game or provide any way to play the game. Whether reading the game's data files this way falls under 6.1.2 is **not stated** by Jagex; the editor ships only a small set of derived facts, never game files.
- **Commercial use (6.1.1):** *"you can't create content using Jagex Property for commercial gain"*.
- **Revocation (11.3):** Jagex can revoke the right to use Jagex Property at any time and for any reason. It usually asks first (9.1).
- **Licence back to Jagex (7.2):** distributing content under the policy grants Jagex a royalty-free, irrevocable licence to modify and distribute it. This is compatible with MIT.
- Contact for questions (16.1): IP@Jagex.com.

### Naming and trademarks

Neither policy forbids naming the game descriptively. They forbid using the **Jagex logo**, implying endorsement, and imitating Jagex content (6.1.6). The project follows these rules:

- The name is **"Dragonwilds Save Editor"**, described as "an unofficial save editor *for* RuneScape: Dragonwilds". "RuneScape" is not part of the brand, and the project never calls itself official.
- No Jagex or RuneScape logos, game art, icons or fonts are used in the app, the repository or the release page.
- The trademark line "RuneScape, RuneScape: Dragonwilds and Jagex are trademarks of Jagex Limited." appears in the README and CREDITS.md.
- The editor is free: no paywalls, no donation links in the tool, no ads.
