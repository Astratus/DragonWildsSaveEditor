## Code and file formats

- **Steve Streeting (sinbad), [SPUD](https://github.com/sinbad/SPUD)**: the Unreal Engine persistence plugin
  that defines the world-save container format (MIT License, Copyright (c) Steve Streeting). `spud.py` follows
  that format but is an independent clean-room implementation; no SPUD code is included
  (see [docs/research/spud_cleanroom.md](docs/research/spud_cleanroom.md)).
- **FabianFG and contributors, [CUE4Parse](https://github.com/FabianFG/CUE4Parse)** (Apache License 2.0): used as a
  format reference for Unreal Engine's IoStore containers, zen packages, unversioned properties, FText and string
  tables while writing the editor's own read-only game-data reader (`dragonwilds_save_editor/gamedata/`). No
  CUE4Parse code is included; every layout was checked against the game's own files
  (see [docs/research/gamedata_provenance.md](docs/research/gamedata_provenance.md)).

## Data

- **The game itself.** The editor's **bundled item and unlock-name catalog** is our own compilation of Jagex game
  data (IDs, names, stack sizes, inventory tabs, unlock names), generated by our own code from an installed copy of
  RuneScape: Dragonwilds (read only). **Help > Update item catalog** runs the same build on the player's machine
  from the player's own installation. The fixed lodestones, Sanguine Urn and kebbit-burrow IDs and the map-region
  (fog bit) names were verified against the installed game's world level with the same reader.
- **RSDWArchive, [RSDWArchive](https://github.com/RSDWArchive/RSDWArchive)** ([rsdwarchive.com](https://rsdwarchive.com)):
  the build 1.0.2.0 game-data dump.
  - It is the research source for the **main-questline checkpoints** (its quest flows) and for the parts of the
    **map and lodestone data** that could not be confirmed from the installed game: the sub-region part of the
    Sanguine Urn and kebbit-burrow names (from its world-map texture and region splines), the areas' quest gating,
    and the lodestones' area names (region polygons). The map and lodestone IDs, locations and region names
    themselves were first datamined from it and later confirmed from the installed game.
  - For the item catalog it is now used only for cross-checking (see below).
  - RSDWArchive has no licence file; the data in it is Jagex's game content, extracted from the game client.
    No file of the dump is shipped.
- **Frederik Stenberg Pedersen, [dragonwilds-completionist](https://github.com/FrederikStenbergPedersen/dragonwilds-completionist)**:
  the quest ID to quest name map and vestige recipe IDs. MIT licence; its notice is reproduced under
  [Third-party licence notices](#third-party-licence-notices).

## Used for cross-checking during development (no code or data shipped)

These projects helped while the editor was built. Their data was used only to verify ours (item IDs, stack sizes, durability, XP, save-format details) and to measure the coverage of the generated catalog. No code or data from them is included.

- **OogaBoogaCode, [RSDWSaveEditor](https://github.com/OogaBoogaCode/RSDWSaveEditor)**: its item catalog and world-save editor were
  an early reference; an earlier version of this editor was based on them, and they were replaced before release.
- **RSDWArchive, [RSDWArchive](https://github.com/RSDWArchive/RSDWArchive)**: before the catalog was built from the
  installed game, it was generated from this dump (build 1.0.2.0). The catalog built from the game (1.0.2.2) was
  checked against that earlier build: every item and unlock ID and every field agreed, and the game build adds 51
  newer AI entries.
- **RSDWArchive, [RSDWTools](https://github.com/RSDWArchive/RSDWTools)**: its item catalog (stack sizes, inventory tabs) and recipe
  and spell lists, used to check the generated catalog.
- **haithemobeidi, [RSDragonWilds-WorldEditor](https://github.com/haithemobeidi/RSDragonWilds-WorldEditor)**:
  save-format documentation (SAVE_FORMAT.md, including the SpudCache tip) and `guid_map.json`, used to cross-check item IDs.
- **Elleandria, [RS-Dragonwilds-Editor](https://github.com/Elleandria/RS-Dragonwilds-Editor)**
- **KevinStillman, [dragonwilder](https://github.com/KevinStillman/dragonwilder)**
- **TatsumaYakoshi, [DragonWilds-Ultra](https://github.com/TatsumaYakoshi/DragonWilds-Ultra)**
- **ChaniAtreides, [RSDragonwildsNotT10](https://github.com/ChaniAtreides/RSDragonwildsNotT10)**: a public sample save used to check quest states.
